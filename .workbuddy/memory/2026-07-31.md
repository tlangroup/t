## M30 map 字面量 + for-in 迭代 ✅

延续 M29（map 内建端到端），补齐 map 的两块使用体验，并顺手修掉一个静默正确性 bug。

### 交付
- **map 字面量**：`var m: map[K]V = [k1: v1, k2: v2];`。解析层（`parse_map_lit`）早已存在，本次补 emit 路径。
  - `is_map_lit(e)` 助手；C 后端 `emit_stmt` 的 var_decl 分支、LLVM `ll_local_decl` 各加一段。
  - 与切片字面量同范式：`t_map_new`/`tll_map_new` + 逐项 `put`。
  - **`var m: map[K]V;` 无初始化时也建空表**（此前是未初始化指针），声明即可用，不必再 `m = map_new(m)`。
- **for-in 迭代键**：`for (k in m) { … }`，按插入序，绑定变量类型 = K。
  - runtime 已有 `t_map_count`/`t_map_key_str_at`/`t_map_key_int_at`，只需 3 个 `tll_*` shim（str 版走 TStr 出参）。
  - `check_stmt` 的 for_each 加 Map 分支（et = key）；`collect_local_types` 加 `cat=="map"` → `fs_set(key)`。
  - C/LLVM 双后端 for_each 各加 map 分支；`emit_lldeclares` 加 3 条 declare。
- **map 字面量类型推断**：整型键/值统一提升 i64（复刻 array_lit 规则），否则 `["a": 1]` 推成 `map[string]u8` 与声明失配。

### 修掉的静默 bug：窄整型键
`map[i32]i64` 此前 `map_get` 恒返回 0（len 正常、迭代正常，只有查不中）。根因：runtime 按 `int64_t*` 读键，而后端直接对 i32 变量取址 → 高 4 字节是栈垃圾，put 与 get 时不同。
修法：**整型键一律按 int64 落盘**。
- C：`&(int64_t){(int64_t)(<expr>)}`（C99 复合字面量是左值）。
- LLVM：新增 `ll_map_keyptr(kn, keytd)`，非聚合键一律 `ll_map_argptr(kn, td_named_mk("scalar","i64"))`，内部会先 `ll_cast_v` 扩宽。
- 附带收益：**键与值都可以直接写字面量了**（`map_set(m, "k", 11)` / `map_get(m, 8)`），此前受 C 后端取址限制必须先存局部变量。值侧同样用复合字面量 `&(V){(V)(expr)}`（仅标量；聚合仍取原表达式地址，C 不允许 cast 到 struct）。
- 新增 `call_arg_node(cid, ix)` 助手：C 后端 map 分派需要实参**节点**（不只是已发射的字符串）来反查类型。

### 复用经验
- **M29 加的两个守卫脚本这次立刻见效**：`tools/catn_check.mjs` 一次抓出 5 处 `catN` 实参个数不符（写代码时很容易 cat6 只给 5 个）。新增 LLVM 发射代码后先跑 `catn_check` + `shadow_check` 再编译，能省一轮编译周期。
- 运行时正确性必须靠 `examples/*.tc` 实跑 + `.expected.txt` 固化 + C/LLVM 交叉 diff；conformance 只做静态检查，difftest 只比 lex/parse/check 的 stdout。
- 涉及 runtime 按固定宽度读写的场景（map 键、slice 元素），后端取址前要确认宽度对齐，否则是**静默错值**而非崩溃。

## M31 map 收尾四块 ✅

用户全选四块：M31a 参数/返回值、M31b for(k,v in m)、M31c 嵌套 map + 字面量作表达式、M31d 字面量非局部位置（全局 var / 结构体字段）。

### 关键改动
- **M31a**：类型层（resolve_type_desc/ti_equal/desc_to_c/ll_td）+ 双后端发射层天然支持，零改动。实证 `fn(m: map[K]V)->map[K]V` 正确。
- **M31c**：`emit_lle`(LLVM) 补 `map_lit` 分支（`ll_build_map_lit`→`ll_tmp()` 返回），此前漏分支对 map_lit 返 `"0"` 致 `store ptr 0`/`call i64 @t.count_keys(ptr 0)`；C `emit_expr` 同补复用 `c_emit_map_lit`。`map[K]map[K2]V` 逐层 OK。
- **M31b**：`for_each` 节点加 `sb`（值变量名）；parser + `src/totter.tc` 的 `emit_forx` 支持 `(k, v in m)`；checker 对非 map 双变量报 `T_TYPE_MISMATCH`；`collect_local_types` 对 `sb` 设 `itd.val`；C/LLVM 经 `t_map_val_at(m,i)` 绑定值；runtime 加 `t_map_val_at` + `tll_map_val_at` shim。
- **M31d**：C 不允许运行时调用作文件作用域初始化器 → 引入 `glines` 缓冲 + `g_spush_to_ginit` 开关，把非常量初始化器搬进 `t__ginit()`（main 开头调用）；`g_stmt_pad` 供 map 字面量分支对齐缩进。双后端产物逐字节一致。
