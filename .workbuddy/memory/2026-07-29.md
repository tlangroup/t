- 用户手动装 LLVM（clang 22.1.8, `C:\Program Files\LLVM\bin\clang.exe`）；实现 `.tc → .ll → exe` 直达管线。
- 新命令：`tc1 emit-ll <f.tc> [--output]` 与 `tc1 build <f.tc> [--output] [--clang] [--runtime]`（clang -O1 链接 t_runtime.c + t_shim_ll.c）。
- **值模型**：标量=SSA（bool 存 i8，分支处转 i1）；聚合（string/slice/struct/variant/union）=指向入口块 alloca 的 ptr；所有 alloca 在 entry 块（循环安全）。运行时经 `runtime/t_shim_ll.c` 指针化 `tll_*` 桥（规避 Win64 聚合 ABI）；模块内 t 函数间聚合按值传。
- 类型映射：`%st.Name`/`%vt.Name={i64,[N x i8]}`/`%un.Name={[N x i8]}`/`%TStr={ptr,i64}`/`%TSlice={ptr,i64,i64,i64}`；用户函数 mangle 为 `@t.<name>`；全局在 `@t.__ginit()` 初始化；main 包装 runtime_init/arena/done。
- flag=内联位运算（lshr/and、and-not/or）；enum 成员访问=底层标量常量；variant 助手 GEP tag/payload。
- **不动点回归修复**：tc1 C 后端曾把 `sys_run` lower 成 `t_system(...)` 而 tc0 是直通 `sys_run(...)` → C_a≠C_b。修复：tc1.tc:5292 改回直通 `sys_run(`，t_runtime.h 加 `#define sys_run(cmd) t_system(cmd)`（108 行）。
- 验证全绿：bootstrap 不动点 OK、difftest 15/15、conformance 17/17、lltest/hello.tc + full.tc（STRUCT/ENUM/SLICE/STR/SB/FLAG/VARIANT/FOR/CAST/GLOBAL 全 OK，RC=0）。
