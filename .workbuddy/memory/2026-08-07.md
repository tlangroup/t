## 第一个标准库 std（lib/std，mem + math）✅
- **目标**：在 `lib/std` 落地首个标准库（mem + math），并解决「tc 模块 ↔ std 模块」相互依赖。
- **依赖架构（核心解法）**：① std 对 tc **零语义依赖**——只依赖语言内建 + 运行时（`runtime/t_runtime.c`），绝不引用 tc 私有符号 ⇒ `std→tc` 不存在；② 构建期 `node tools/build_std.mjs` 用现有编译器把 mem/math 预编译为 `out/lib/{mem,math}.tlib`(+`.tlibd`)，消费方链接模式 `import @std.mem`/`@std.math` 消费，斩断 `tc→std` 构建循环。`tc0` 不识 `import @x`/`export` ⇒ 自举首代 tc 须保持 std 无关。
- **交付物**：`lib/std/mem.tc`（泛型切片工具 copy/equal/fill/reverse/swap_in/index_of/contains/len）、`lib/std/math.tc`（泛型 min/max/clamp + 整数 abs/sign/div_floor/div_ceil/mod_e/log2/pow2_i/is_pow2/gcd/next_multiple_of/lerp_i + 浮点 fabs/floor_f/ceil_f/round_f/trunc_f/sqrt_f/pow_f/lerp_f/sin_f/cos_f/exp_f + const PI/E）、`tools/build_std.mjs`、`examples/std_demo.tc`、`tests/conformance/pass/p42_std_import.tc`、`docs/std.md`。gate L0 接 `boot_std` 步骤（boot1 前）。
- **关键实测坑**：① 编译器**泛型函数体内嵌套泛型调用不被单态化**（链接期 `undefined @t.xxx`）——`clamp`/`reverse`/`contains` 已内联规避；编写 std 泛型函数勿嵌套调泛型；建议修 `instantiate_generic`。② `export` 不能修饰 `import`（`T_EXPORT_SCOPE`）⇒ 无 `import @std` 门面，须 `import @std.mem`。③ `t` 不支持 `&`/`*` 作表达式 ⇒ 无裸指针/字节级 memcpy/swap(两标量)。④ 浮点比较/cast/`as` 双后端 OK。
