## FuncType v2 Stage B1：统一 TClosure ABI（非捕获路径，M47）✅

- **动机**：Stage A 的函数值 = 裸函数指针，无处安放捕获环境。Stage B 要做按值捕获闭包，必须先把**函数值的表示**统一成「码 + 环境」二元组，否则捕获/非捕获两种函数值不可互换赋值。
- **ABI 定型（本次关键决策）**：函数值 = **`TClosure*` 指针**（不是按值结构体）。
  - C 后端 → `TClosure*`；LLVM 后端 → `ptr`（沿用 v1 不透明指针）。
  - **为什么是指针不是值**：`ll_isagg` 对 func 返回 false，若改成按值 `%TClosure` 聚合会踩项目红线「LLVM 避 Win64 聚合 ABI」，且 v1 所有 `ptr` 路径要重写。用指针则 LLVM 侧类型层**零改动**，只需改「取值点」与「调用点」。
  - 底层被调函数统一 `Ret (*)(void* env, Args...)`，**env 为首参**。
- **trampoline（必需，别想省）**：顶层具名函数的 C/LLVM 定义是 `Ret g(Args)`，没有 env 首参；直接强转会让 env 挤掉首个真实参数。故为每个**被取值**的函数生成一层 static trampoline 吃掉 env 再转发：
  - C：`static Ret __tramp_g(void* __env, A0 __a0, ...) { (void)__env; return g(__a0, ...); }` + `static TClosure __tclos_g = { (void*)__tramp_g, NULL };`，输出到**头文件尾部**（此时全部原型已在其上方，.c 首行 include 该头文件）。
  - LLVM：`define internal Ret @t.tramp.g(ptr %__env, ...)` + `@t.clos.g = internal global %TClosure { ptr @t.tramp.g, ptr null }`。
  - 惰性收集：`clos_names` + `clos_mark()` 只为真正取值的函数生成，避免为全库 460 个函数产出无用代码。
- **踩坑：AST 标记法行不通（已回退）**。最初想在 checker 给「函数值引用」节点打 `n.ib=1` 标记供发射期 O(1) 判定，结果 `apply2(mul, 6, 7)` 发出 `@t.mul` 而非 `@t.clos.mul`（运行到第 3 行即崩）。
  - **根因**：`infer_expr` 的 call 分支对**直接调用顶层函数**是 `return resolve_ti(fd.na);` **直接返回，根本不遍历实参** —— 所以实参位置的 ident 永远拿不到标记。（推论：t 的 checker 对直接调用**不做实参类型校验**，靠 C 原型兜底；间接调用才有 `check_indirect_call`。这是既有设计缺口，勿在此顺手补，会让 16K 行源码冒出大量新诊断。）
  - **改法**：不依赖 checker 标记，发射期就地判定 —— 凡走到 `emit_expr`/`emit_lle` 的 **ident 分支**且解析到 FuncDecl 的标识符，必然是「函数作为值」，因为**直接调用的 callee 不经 ident 分支**（call 分支直接读 `cal.sa`）。C 侧用 `clos_decl_of(name)>=0`（局部/参数优先：先查 `fs_get`），LLVM 侧用已有的 `llfn_find(name)>=0`。
- **改动点**：`td_func_c_decl` 删除→`td_func_c_fnptr`（只生成调用点强转类型 `Ret (*)(void*,A...)`）；`c_decl_of`/`c_ptr_to`/`c_decl_of_node` 的函数指针特例全删（TClosure* 是普通指针）；`emit_ctype`/`desc_to_c` func 分支→`TClosure*`；`c_elem_ctype` 的 func 退化 `void*` 特例删除；`emit_expr` ident/call 分支；`emit_lle` ident；`ll_call` 间接调用解包；`emit_llunit` 加 `%TClosure` 类型；新增 `emit_c_closures`/`emit_ll_closures`/`clos_mark`/`clos_decl_of`/`clos_callee_td`。
- **门禁全绿**：conformance 48/48；run_examples 双后端 dbg 14/14 + rls 14/14；三阶段自举不动点 md5 **`3b8ec05600782538db5b0a060b224d0c`**（b2==b3==b4）；`; UNSUPPORTED` 计数 0；shadow_check（460 函数/2577 var，非假绿）+ catn_check OK；difftest 代际对拍 27/27；tc0 外部对拍 lex/check 9/9 绿（emit-c 仍 0/9，既有基线）；tote 端到端 `tote run examples/lambda_demo.tc` 通过。
- **b1 vs b2 的 IR 差异只有 1 行**（新增 `%TClosure = type { ptr, ptr }`），确认 tc.tc 自身不使用函数值，ABI 变更对自举无影响。
