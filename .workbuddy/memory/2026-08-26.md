## 全量 comptime —— enum/variant 加入 CTFE（已完成并端到端验证）

用户指令「enum/variant加入 comptime」。变体值在运行期是带 tag 的 blob（`emit_ctype` 对 variant 返 `void*`），**不适合折成 codegen 常量**（构造器是运行期分配）。改为把变体做成「编译期一等值」：构造器产出仅存于 `meta_eval` 内部的 `vval` 节点，`is`/`as`/`match` 消费它产出可 codegen 的标量/结构结果。

### 改动
**src/base.tc**
- 节点种类注册表新增 `vval`（仅存在于 meta_eval 内部，永不进 emit_expr）。
- 新增 `mk_VVal(sa=变体类型名, ia=tag, sb=case名, la=载荷值链)`。

**src/sema.tc（meta_eval 扩展）**
- `meta_eval_call` 顶部、普通 meta fn 派发前拦截变体辅助函数：
  - `Name_from_Case(载荷)` → 求各载荷、`mk_VVal` 产出变体值（`variant_find_case` 取 tag）。
  - `Name_is_Case(self)` → 比对 tag 返 `mv_bool`。
  - `Name_as_Case(self)` / `Name_as_Case_fK(self)` → 取对应载荷（多载荷逐字段）。
  - 非变体辅助调用返回 -2 交后续派发。
- 新增字符串工具 `meta_str_find` / `meta_substr`（无 sb_split 原语，手搓）；`meta_lit_eq`（字面量相等）；`meta_bind_conpat`（conpat 子模式链绑定到载荷值链，支持嵌套 conpat）；`meta_eval_match`（scrutinee 求值→按 conpat/`_`/字面量 选臂、过 `when` 守卫、求值命中臂体）。
- `meta_eval` 派发器新增 `match` 分支。

**src/comptime_fold.tc（diffuse 折叠）**
- `comptime_is_candidate` 新增 `match`。
- `comptime_has_runtime_ref`：`conpat` 子树（纯模式，绝无运行期值引用）返回 false；`call` 若为变体辅助（`comptime_call_is_variant` 按 `_from_`/`_is_`/`_as_` 前缀判定，放行并递归检查实参）则放行。
- `comptime_fold_pass`：match 节点跳过「含运行期引用」护栏（其 scrutinee/body 的标识符多为模式绑定，由 `meta_eval_match` 在 menv 内求值），直接尝试 `meta_eval`，失败优雅放弃（quiet 无伪诊断，g_meta_err 复位）。

### 验证
- **探针1（diffuse 单载荷 match）** `out/dbg/_v1.tc`：C 产物 `int64_t x = 6; int64_t y = 9;`（两条 match 整条折常量）；运行期 `x==6 && y==9` → 返回 1。✓
- **探针2（meta fn 内 is/as，多载荷）** `out/dbg/_v2.tc`：`classify(Shape_from_Circle(7))`/`classify(Shape_from_Rect(3,4))` → a=70/b=7；运行期返回 1。多载荷 `_f0`/`_f1` 访问器在 CTFE 内正确求值。✓
- **探针3（diffuse 多载荷 match + when 守卫 + `_` 通配臂）** `out/dbg/_v3.tc`：C 产物 `a=7, b=99`；运行期返回 1。✓

### 关键结论
- enum/variant 现作为编译期一等值可用：`from` 构造、`is` 判别、`as` 取载荷、`match` 解构（含 `when` 守卫、多载荷、`_` 通配、嵌套 conpat）均能在 comptime 求值。
- 设计严守既有约束：变体值不进 codegen（仅 `vval` 瞬态），`match`/`is`/`as` 的**结果**才是可 codegen 常量，故双后端等价与四代不动点不受影响。
- 注意 `meta_eval` 暂不支持浮点，故变体载荷若为 `f64` 无法在 CTFE 构造（探针改用 i64 载荷）。
