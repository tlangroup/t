# 2026-08-05 工作日志

## 选项①收尾：修 path_exists + toml 自动定位工程根（src/tc.tc）

### 根因（OOM）
- `compute_src_roots` 旧 walk 在循环体内调用 `path_resolve(mod_dir_of(cur))`。
  `path_resolve` 走 `_fullpath`；走到盘符根 `C:` 时 `_fullpath("C:")` 把「C 盘当前目录」展开成
  `C:/Users/seesaw`，于是 `C:/` ↔ `C:/Users/seesaw` 来回震荡，`parent==cur` 永不触发，
  每次 `path_resolve`+`sb_cat` 都从 arena 分配 → `arena: out of memory`。
- 叠加：仓库根 `t/tote.toml` 存在，walk 一路爬到仓库根把 `t/src` 加进候选源码根，import 解析空间被污染。
- 旧版还埋了 `sb_cat3(cur,"/tote.toml")` 只有 2 实参（catn 静态检查才抓出；LLVM 后端不支持 sb_cat2..6）。

### 修法（已落地并验证）
- 新增纯字符串 `parent_dir_of`（剥尾斜杠、找最后 `/`或`\`，盘符根/无分隔符返回 ""），循环内**完全不碰 `path_resolve`/`_fullpath`**，杜绝震荡。
- `compute_src_roots`：入口目录仅一次 `path_resolve` 兜底；向上遍历用 `parent_dir_of`，硬上限 `guard<32`。
- 拼接改走 `StringBuilder`（`sb_new`/`sb_append_str`/`sb_to_str`），不用 `sb_cat2`。
- `path_exists` 维持调 `file_exists` 内建（上一轮已改，根除绝对路径下 sys_run 外shell OOM）。

### 验证
- `tc.new.exe.exe check/run examples/proj_demo/src/main.tc` → `hi from hello`/`5`/`110`，0 诊断。
- 回归 `agentkit_demo.tc`（`recorded frames=4` 等）、`module_hello`（hello from main/6/hello,world）均通过，新加 `t/src` 候选根无误命中。
- L0 gate：静态检查 PASS、自举一代 PASS、产物快照比对进行中（待结束）。

## 经验（下次别再踩）
- **gate 千万别放后台**：记忆里写过「管道静默挂起」，前台跑更可控。
- **`sb_catN` 实参必须 == N**，且 LLVM 后端不支持 `sb_cat2..6` → 多段拼字符串一律 `StringBuilder`。
- `eprint` 在 arena abort 时缓冲不刷出，死循环/OOM 现场看不到 → 排查路径分配类 bug 直接改逻辑而非靠 eprint 追踪。
- OOM 类 bug 优先「消除分配来源 + 硬上限」而非「加 guard 放行」——`guard>64` 看似有上限，但震荡里终止条件永不成立的死循环仍会跑满上限且每次都分配。

## 外部库 Phase 1：搜索路径 + 命名空间隔离（src/tc.tc，已落地并全绿验证）

### 设计（用户拍板 q-0/q-1/q-2）
- `import @json + 约定搜索路径`；`.tlib` 预编译产物留 Phase 2；`加前缀 + 限定访问`（库顶层符号 → `lib__name`，仅经 `lib.sym(...)` 访问，库内自调用也脱糖 `lib__sym`）。

### 实现要点
- **搜索路径 `compute_lib_dirs`**：去 `getenv`（非内建）；入口目录 `lib/`/`libs/` 优先，其次各 `<src_root>` 父目录（工程根）的 `lib/`/`libs/`。`resolve_external_lib` 候选 `<libdir>/x.tc`→`/x/index.tc`→`/x/lib.tc`，全失→`T_IMPORT_NOT_FOUND`。
- **命名空间重整 `mangle_modules`**（取代旧 `desugar_module_qualifiers`）：Pass1 处理限定访问（`A.sym`→`A__sym`，可见性校验）、`A.T`/`A.T{}` 重整；Pass2 库内符号整写 `A__name`。入口模块别名 `""` → 永不重整 → **单文件 IR 逐字节不变**。
- `parse_type` 加 `A.T` 限定类型；`parse_prim_ident` 加 `A.T{...}` 限定字面量；`clone_type_node` 深拷贝补齐 `sb`（修复 agent state 字段克隆丢 `physics.` 前缀退化 i64 的 LLVM link 错）。
- 新诊断 `T_MODULE_PRIVATE`（未导出跨模块访问）、`T_MODULE_NO_SYMBOL`（限定类型/符号找不到）。

### 验证
