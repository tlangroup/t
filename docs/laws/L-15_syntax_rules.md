# t 语言语法规则法

> **法律编号：L-15** ｜ 名称：t 语言语法规则法 ｜ 制定依据：《t 语言设计宪法》第2条(唯一确定语义)、第3条(全行为显式)、第1条(静态类型)、第13条(铁律校验)
> **状态：草案（待宪法审查）**
> 本法律为细则法,规定语法规则的书写格式、法律验证要求与起草工作流。语法规则是法律之下、用于精确界定 t 语言词法 / 句法形式的子层规范,最终并入 `docs/reference.md` 成为语法权威载体。

---

## 第一章 适用范围

- **第1条 适用对象** — 本法律约束 t 语言一切语法规则的制定与修订,包括:词法产生式、句法产生式、注解(`@xxx`)形式、字面量形式、语句 / 表达式形式、优先级��结合性约定。
- **第2条 不适用** — 编译器内部实现细节、运行时数据结构布局(除非以语法形式暴露)不属本法律范围,由对应细则法 / 契约法约束。

---

## 第二章 正文条款

- **第3条 语法记号强制(符合 reference.md §1 Notation)** — 所有语法规则必须以 `docs/reference.md` §1《Notation(记号约定)》规定的**类 BNF 产生式**为唯一规范记号(呼应宪法第2条唯一确定语义),具体须遵守:
  - 产生式形式 `ProductionName: Syntax`(冒号分隔,**禁用** `::=` 等其他分隔符);
  - `|` 分隔可选项,`( ... )` 分组,`?`/`*`/`+` 表可选 / 0+ / 1+ 重复,`>>>` 表向前看消歧;
  - 字面量用等宽 `"..."`(关键字 / 标点);非终结符首字母大写(`Ident`、`IntegerLiteral`),终止符(token 类别)小写(`ident`、`int`、`lbrace`);
  - `ebnf` 代码块内注释仅用 `//` 行注释与 `/* ... */` 块注释,状态注记(`⚠ spec-only`、`✅ tote` 等)写在注释内部,由 `tools/gen_ebnf.mjs` 结构化抽取进 `out/ebnf.json` 的 `rules` 段(生成器只消费 `tote`/`partial` 条目);
  - 禁止以自然语言散文、伪代码或多种等价记号变体表述同一规则;
  - `docs/reference.md` 为语法根本源(single source of truth),其 `ebnf` 产生式块即文法的机器可读表示,本法律不与 §1 冲突。
- **第4条 必须通过法律验证** — 任一语法规则在生效前,必须通过下列法律的验证(验证方式见第5条四层评审):
  - **L-04 唯一确定语义法** — 不得引入等价多写法;
  - **L-02 全行为显式可追溯法** — 语法不得隐含类型转换 / 布尔判定 / 内存分配 / 生命周期;
  - **L-03 静态类型前提法** — 语法须保持编译期类型安全、固定位宽;
  - **L-14 铁律校验法** — 须纳入 conformance / difftest 等门禁,可机械复验。
- **第5条 起草工作流(草稿 → 采纳 → 并入 → 失效)** — 每当编写新的语法规则,须遵循:
  1. **启动草稿文件** — 在 `docs/syntax/drafts/<rule-name>.md` 建立草稿,以规范 EBNF 书写该规则及释义;
  2. **法律验证** — 依第4条提交法律验证,取得四层评审意见(✅ / ⚠️ / ❌ / 🚫);
  3. **规则采纳(定稿)** — 经用户明确采纳指令(取得 ✅ 或经确认的 ⚠️)后,草稿转为已生效语法规则;
  4. **并入 reference.md** — 将草稿中的 EBNF 规则与释义并入 `docs/reference.md` 的语法章节,成为语法权威载体;
  5. **草稿失效** — 并入完成后,原草稿文件头部标记「状态:已并入 reference.md(失效)」,保留于 `docs/syntax/drafts/` 作历史追溯,不再据以执行。
  - **术语澄清(采用法律级采纳)** — 本法中"**生效**"一词**专指法律级采纳**:即 L-15 本身依宪法第19条 / 本法第7条、经宪法审查取得 ✅ 或确认 ⚠️ 后生效。第3步为**规则级采纳**(草稿→定稿),与法律级采纳不同,不得混用"生效"表述。
  - **迭代修订** — 已生效并并入 `docs/reference.md` 的语法规则若需**再次修改**,须将该规则从 reference.md 摘出、新建或复用 `docs/syntax/drafts/<rule-name>.md` 并**重新置为草稿状态**,重启本工作流(草稿 → 法律验证 → 规则采纳 → 并入 → 草稿失效);同步在 reference.md 对应条目标注修订版本号。
- **第6条 权威载体** — `docs/reference.md` 为语法规则最终权威;草稿文件仅为过渡载体。任何语法争议以 reference.md 中已生效条目为准;与本法冲突时以宪法 / 上位法律为准。

## 第三章 与宪法关系

- 本法律落实宪法第2条(唯一确定语义,对应第3条 EBNF 单一记号)、第3条(全行为显式,对应第4条验证项)、第1条(静态类型,对应第4条验证项)、第13条(铁律校验,对应第4条门禁)。法律之间依 L-01 第2条(特别法优于一般法)裁决。
