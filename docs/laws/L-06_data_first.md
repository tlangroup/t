# t 语言法律 · 数据一等公民法

> **法律编号：L-06** ｜ 名称：数据一等公民法 ｜ 制定依据：《t 语言设计宪法》第一章第5条（数据一等公民驱动架构原则）
> **状态：草案（待宪法审查）**
> 本法为细则法，将宪法第5条「数据一等公民驱动架构」落实为可检查的代码约束：结构体、枚举、Flag 位域、注解、外部数据表导入为一等公民，业务逻辑弱依附于数据定义。

---

## 第一章 适用范围

- **第1条 适用对象** — 类型系统（struct / enum / flag / variant / 注解）、数据导入机制（`import_json` / `import_csv`）、被编译的 t 程序数据定义、示例 `examples/*.tc`。
- **第2条 不适用** — 编译期类型自省（`type_info`）的运行时接口细节由相应细则法补充。

---

## 第二章 正文条款

- **第3条 复合类型一等公民** — struct / enum / flag（位域）/ variant 均为语言内建一等公民，可独立定义、传递、存储，无需借助底层指针技巧。
- **第4条 注解一等公民** — 注解（`@xxx`）为结构化元数据，编译期可经 AST 读取与处理，驱动代码生成（如 `@derive`）。
- **第5条 外部数据表导入** — 支持 `import_json` / `import_csv` 在编译期将外部数据表导入并固化为静态常量。
- **第6条 数据驱动** — 业务逻辑弱依附于数据定义；数据 schema 的变更应可静态推导其对逻辑的影响。

---

## 第三章 与宪法关系

- **第7条 宪法映射** — 本法对应宪法第5条（数据一等公民驱动架构）；与第4条（AST 元编程，注解驱动生成）、第12条（ECS 数据并行）协同。
