# t 语言法律 · 确定性可复现编译法

> **法律编号：L-08** ｜ 名称：确定性可复现编译法 ｜ 制定依据：《t 语言设计宪法》第一章第7条（确定性可复现编译原则，构建层）
> **状态：草案（待宪法审查）**
> 本法为细则法，将宪法第7条「确定性可复现编译（构建层）」落实为可检查的代码约束：同源码跨环境 / 跨时间产出逐字节一致的构建产物。

---

## 第一章 适用范围

- **第1条 适用对象** — 编译器 `src/tc.tc` 的输出（`.ll` / `.c` / 二进制）、构建工具链（`tools/build_runtime.mjs` 等）、`out/` 产物。
- **第2条 不适用** — 运行期非确定性（如并行顺序）由《协程并行资源绑定法》(L-13) 规制。

---

## 第二章 正文条款

- **第3条 无时间 / 随机污染** — 构建产物不得嵌入 `__DATE__` / `__TIME__` / 随机种子 / 构建机器标识。
- **第4条 无环境泄露** — 产物不得包含绝对路径、用户名、临时目录等环境相关字符串。
- **第5条 确定迭代顺序** — map / 集合 / 字典的迭代须为确定顺序（插入序或确定排序），不依赖哈希随机化。
- **第6条 字节级可复现** — 同源码在相同工具链版本下，跨环境、跨时间产出逐字节一致。

---

## 第三章 与宪法关系

- **第7条 宪法映射** — 本法对应宪法第7条（确定性可复现编译，构建层）；与第2条（同输入同行为）、第12条（并行顺序无关）协同保障确定性。

---

## 第四章 合规判据

| 条款 | 合规判据 | 当前实现状态 |
|---|---|---|
| 第3条 无时间/随机 | 源码与产物无 `__DATE__` / `rand` 注入 | ✅ |
| 第4条 无环境泄露 | 产物无绝对路径 / 用户名 | ✅ |
| 第5条 确定迭代 | map 按插入序迭代 | ✅ |
| 第6条 字节可复现 | `difftest` 逐字节不动点成立 | ✅（dbg vs rls 27/27） |

- **第8条 生效** — 本法经宪法审查取得 ✅ 或确认⚠️ 后生效。
- **第9条 修订** — 任何修订须依《法律总则》(L-01) 第三章提交宪法审查，取得四层评审意见后方可生效。
