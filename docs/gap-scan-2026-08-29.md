## 四、P3 · 工具链

- **无 formatter**：宪法 L-12「强制格式」无法机械执行（`tc` CLI 只有 `help/test/lex/check/emit-ll/build/run`；`tools/` 无 fmt）。
- **无 LSP / 编辑器支持**。
- **无 CI**：无 `.github/workflows`，`tools/gate.mjs` 只能本地跑。
- **无文档生成器**、**无 bench / 性能回归**。
- **无包注册中心**：`tote` 有 `init/build/run/deps/install`，但无远程源。
- REPL 为 clean-subprocess 模型，跨行可变状态不持久（`docs/repl.md`）。

## 五、P4 · 运行时内存

- 闭包 env 与 `TClosure` **只分配不回收**（v1 有意为之，`reference.md` L1225；`lifecycle.md §6`）。
- 全局 arena **进程末一次性释放**（`t_arena_free_all`），长驻进程内存单调增长。
- `defer` **仅函数级**，块级作用域退出不触发（`lifecycle.md §6`）。

## 六、P5 · 生态与并发

- **并发为零**：`thread` `spawn` `async` `await` 在 src / lib 全零命中；L-13 协程并行法仍是**草案（待宪法审查）**。
- **无网络**：架构红线明确 t 无 FFI / 网络（有意为之）。
- 63 个 example 集中于 agent / ECS / 格式化 / fid，缺网络、并发、数据库、GUI 场景。

## 七、建议顺序

1. **P0-1 `[N]T` 区间索引**：cast lowering 已就绪，只需把 `lower_range_index` 的 Array 分支改为先降级成 slice 再走 `slice_sub`，顺手更新过时注释。
2. **P2 字符串工具 + sort**：投入产出比最高——补 10 个 string 内建 + 1 个 `sort`（六处齐全：builtin_ret / td_calls / C emit / LLVM emit / llph declare / runtime）。
3. **P3 formatter**：L-12 是宪法级要求却无工具，属「法律不可执行」。
