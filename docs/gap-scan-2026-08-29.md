## 三、P2 · 标准库近乎空白（面积最大）

实现面：`lib/` 仅 `std/math.tc`(23 函数)、`std/mem.tc`(8 函数)、`repl.tc`。共 **31 个函数**。
语言层内建（`sema.tc:1569-1726`）约 90 个，集中在打印 / StringBuilder / 切片 / map / fid / 时间 / 格式化 / 类型自省。

| 领域 | 缺 | 现有 |
|---|---|---|
| 字符串工具 | `index_of` `split` `trim` `to_upper/lower` `replace` `starts_with` `ends_with` `repeat` `pad` | 仅 `str_len` `str_at` `str_slice` `int_to_str` `to_string`（`sema.tc:1594-1620`） |
| 排序 / 二分 | **全工程零命中**（src / lib / runtime 均无 `sort` / `bsearch` / `qsort`） | 无 |
| UTF-8 ↔ rune | 无 `utf8_decode` / `utf8_encode` / `rune_count`；`str_len` 是字节数 → **Unicode 半残**（词法能认 UTF-8，运行期无法按码点遍历） | `rune` 类型已落地（`reference.md §3.5.1`） |
| map 工具 | 无 `keys` / `values` / `clear`（`t_map_key_str_at` 在 runtime 但未暴露为内建） | 迭代 `for (k in m)` 已支持（`examples/map_iter.tc`） |
| 文件系统 | 无 `mkdir` `rmdir` `listdir` `remove` `rename` | `file_read_all` `file_write_all` `file_exists` `path_resolve` |
| 进程 | 无 stdout 捕获、无 env 传参、无管道 | `sys_run` 仅返回 `i32` |
| 时间 | 无 `sleep`、无单调计时、无耗时测量 | `now` `format_time*` `parse_time*` |
| 随机数 | 无 `rand` 内建（src 内命中均为编译器内部用途） | 无 |
| 数学 | 超越函数为泰勒近似、未接 libm；无 `log10` `atan2` `hypot` | `std.math` 23 函数（`docs/std.md §4.4`） |
| JSON / CSV | 无运行期解析 / 序列化 | 仅编译期 `import_json` / `import_csv` |
| CLI 解析 | 无 getopt 风格解析 | 裸 `args()` 返回 `[]string` |
| 裸指针 / 字节级内存 | 无 `&` / `*` 表达式运算符 | 无（`docs/std.md §4.3`） |

## 四、P3 · 工具链

- **无 formatter**：宪法 L-12「强制格式」无法机械执行（`tc` CLI 只有 `help/test/lex/check/emit-ll/build/run`；`tools/` 无 fmt）。
- **无 LSP / 编辑器支持**。
- **无 CI**：无 `.github/workflows`，`tools/gate.mjs` 只能本地跑。
- **无文档生成器**、**无 bench / 性能回归**。
- **无包注册中心**：`tote` 有 `init/build/run/deps/install`，但无远程源。
- REPL 为 clean-subprocess 模型，跨行可变状态不持久（`docs/repl.md`）。

## 五、P4 · 运行时内存

- 闭包 env 与 `TClosure` **只分配不回收**（v1 有意为之，`reference.md` L1225；`lifecycle.md §6`）。
- 全局 arena **进程末一次性释放**（`t_arena_free_all`），长驻进程内存单调增长。
- `defer` **仅函数级**，块级作用域退出不触发（`lifecycle.md §6`）。

## 六、P5 · 生态与并发

- **并发为零**：`thread` `spawn` `async` `await` 在 src / lib 全零命中；L-13 协程并行法仍是**草案（待宪法审查）**。
- **无网络**：架构红线明确 t 无 FFI / 网络（有意为之）。
- 63 个 example 集中于 agent / ECS / 格式化 / fid，缺网络、并发、数据库、GUI 场景。

## 七、建议顺序

1. **P0-1 `[N]T` 区间索引**：cast lowering 已就绪，只需把 `lower_range_index` 的 Array 分支改为先降级成 slice 再走 `slice_sub`，顺手更新过时注释。
2. **P2 字符串工具 + sort**：投入产出比最高——补 10 个 string 内建 + 1 个 `sort`（六处齐全：builtin_ret / td_calls / C emit / LLVM emit / llph declare / runtime）。
3. **P3 formatter**：L-12 是宪法级要求却无工具，属「法律不可执行」。
