## 1. EBNF

```ebnf
// 后缀（左结合，可堆叠）；`as` 仅在循环结束后出现一次
PostfixExpr:
    PrimaryExpr (("." ident) | ("[" Expr "]") | ("(" Args? ")"))*
    ("as" Type)?

Args: Expr ("," Expr)*
```

- 词法记号：`.` `[` `]` `(` `)` `)` `as` `,`（与 `parse_postfix` 中 `cur_t()` 判定一一对应）。
- 后缀 `.` / `[ ]` / `( )` 在 `while` 循环中左结合堆叠（如 `a.b[0].c()`），`as` 仅在后缀循环结束后作为尾部可选出现**一次**（非循环内）。
- `Type` 为非终结符，指任意类型表达式（见 `expr.md` 类型产生式引用 / `docs/reference.md` 类型章节）。

---

## 2. Where（编译期约束）

- **后缀左结合、可堆叠（L-03 可预判）**：`a.b[0].c()` 从左到右依次解析，嵌套顺序确定。
- **`as` 显式转换、仅一次（L-02 显式）**：类型转换**仅**经 `e as T` 显式写出，禁止隐式类型转换（隐式转换由 checker 报 `T_TYPE_IMPLICIT_CAST`）；`as` 仅允许一个后缀，不可 `e as T1 as T2`（须嵌套括号 `(e as T1) as T2`）。
- **下标可索引（L-03 静态类型）**：`e[Expr]` 仅对可索引类型（`[]T` 切片 / `[N]T` 定长数组 / `map[K]V` / `string`）合法，由 checker 校验。
- **成员可访问（L-03 静态类型）**：`e.ident` 仅对含该字段 / 方法的类型合法（struct / 具名类型），由 checker 校验。
- **调用参数匹配（L-03 静态类型）**：`e(Args)` 的实参数量与类型须匹配被调用函数签名，由 checker 校验。
- **无隐式布尔 / 隐式分配（L-02 显式）**：后缀层不产生隐式布尔判定或隐式内存分配。

---

## 3. Examples

```t
let a = arr[0];            // 下标
let b = arr[0] as u64;     // 下标 + 显式转换（as 单次）
let c = foo(1, 2).count;   // 调用 + 成员
let d = obj.field.x;       // 成员链式
let e = (x as u32) as u64; // as 嵌套须括号
```

- **单一调用 / 转换写法（L-04 ✅）**：函数调用仅 `f(x)`、显式转换仅 `e as T`、下标仅 `e[i]`、成员仅 `e.f`，无等价多写变体。
