## 1. EBNF

```ebnf
// 前缀一元（右结合，可堆叠：!!x、--x、~~x）
UnaryExpr: ("!" | "-" | "~") UnaryExpr | PostfixExpr
```

- 词法记号：`!` `-` `~`（与 `parse_unary` 中 `cur_t()` 判定一一对应）。
- 一元 `-`（取负）与二元 `-`（减）为不同产生式层级的同一记号：`UnaryExpr` 在塔顶层、`AddExpr` 使用二元 `-`；解析由文法层级唯一确定，无歧义。

---

## 2. Where（编译期约束）

- **前缀右结合、可堆叠（L-03 可预判）**：`!!x` / `--x` / `~~x` 解析为右结合嵌套，每次只套用一个一元算子。
- **无隐式运算（L-02 显式）**：一元运算无隐式类型转换；`-` 取负仅对数值类型合法，由 checker 校验。
- **结果类型静态可定（L-03 静态类型）**：`!` 结果类型为 `bool`；`-` / `~` 结果类型与操作数同（数值 / 位类型），由 checker 推算。
- **不含隐式布尔（L-02 显式）**：一元层不产生布尔隐式判定；`!` 的操作数须为 `bool` 或由 checker 拦截隐式布尔（复用 `T_STMT_IMPLICIT_BOOL` 的判定逻辑）。

---

## 3. Examples

```t
let a = !flag;        // 逻辑非
let b = -x;           // 取负
let c = ~mask;        // 位取反
let d = !!flag;       // 堆叠：!(!flag)
let e = - -x;         // 堆叠取负
```
